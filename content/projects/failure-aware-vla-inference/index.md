This is an ongoing project on using failure detection modules as general plug-in components for VLA-style robot foundation models. The working goal is to reduce unnecessary or low-value inference while preserving reliability in embodied decision-making settings.

## Motivation

VLA-style models can be expensive to query repeatedly during long-horizon embodied tasks. A lightweight failure detection module may help decide when full model inference is needed, when an action should be reconsidered, or when a lower-cost pathway is sufficient.

## Project Direction

- Failure detection as a modular add-on rather than a model-specific redesign.
- Faster inference for VLA-style agents through selective querying or early rejection.
- Reliability-aware monitoring for embodied robot-learning scenarios.
- Evaluation protocols for measuring speed, failure recovery, and task-level behavior.
